# Security Policy

## Reporting a Vulnerability

Report security issues via GitHub Security Advisories ("Report a vulnerability" on this repo) or contact the team on X (@axonprotocol).

Please include: affected contract/module, reproduction steps or PoC, and suggested fix if any.

- Response target: 72 hours
- Contracts are currently TESTNET ONLY — no real funds are at risk
- Do NOT open public issues for unpatched vulnerabilities

## Scope
- `contracts/` (Solidity, testnet) and `soroban/` (Rust, in development)
