# Contributing to AXON Protocol

1. Fork, branch (`feat/your-feature`), commit with clear messages.
2. Solidity contracts must compile with Hardhat and include tests.
3. Soroban contracts (Rust) must build with `cargo build --target wasm32-unknown-unknown` and include unit tests.
4. Open a PR with a short description of what & why.

Questions: open a Discussion or reach out on X (@axonprotocol).
